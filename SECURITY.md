# Security policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues. Use GitHub's private vulnerability reporting form: <https://github.com/BPHvZ/pixel-agents-canvas/security/advisories/new>. Include a concise description, impact, and safe reproduction steps. Do not attach real prompts, transcripts, tool payloads, credentials, local paths, or unredacted logs/screenshots. Redact sensitive data and avoid testing against other people's sessions or systems.

This project is under active development; no guaranteed response or remediation timeline is currently offered. Please allow the owner time to investigate before public disclosure.
