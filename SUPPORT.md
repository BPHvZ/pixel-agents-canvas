# Getting help

- For usage and installation, start with the [README](README.md).
- For a reproducible bug or a concrete feature proposal, use the appropriate [issue form](https://github.com/BPHvZ/pixel-agents-canvas/issues/new/choose).
- For usage questions, check the README and existing issues before opening a question issue.
- For security concerns, follow [SECURITY.md](SECURITY.md); do not post them publicly.

Never include prompts, transcripts, tool payloads, credentials, local paths, or unredacted screenshots/logs in support requests.
